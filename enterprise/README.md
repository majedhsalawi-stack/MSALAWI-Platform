# MSALAWI Enterprise Knowledge Base

This directory is the institutional source of truth for MSALAWI Platform.

## Founding principle
**We build the institution first, then the system.**

نبني المؤسسة أولًا، ثم نبني النظام.

## Vision
To become the reference platform for managing and governing nonprofit-sector institutions through a secure, scalable institutional digital environment supporting compliance, transparency, and operational efficiency.

## Architecture principles
- Governance by Design
- Business Before Technology
- Domain Before Database
- Platform Before Modules
- Multi-Tenant by Design
- Policy Driven
- Workflow First
- Audit by Default
- Security by Design
- Native Arabic/English experience
- Configuration Before Customization
- Product Before Project
- Enterprise Knowledge Preservation

## Sprint 1
Sprint 1 establishes the enterprise domain foundation: business capabilities, bounded contexts, organization, governance, workflow, security, master data, glossary, and architecture decisions before feature implementation.
